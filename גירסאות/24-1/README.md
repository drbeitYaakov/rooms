# מערכת שיבוץ חכמה לכיתות וחדרים

## סקירה כללית

מערכת שיבוץ חכמה לניהול כיתות אם, הקבצות, פגישות ואירועים במוסד חינוכי. המערכת כוללת:

- 🧠 **מנוע שיבוץ אינטליגנטי** עם היגיון עדיפויות
- 🔐 **מערכת הרשאות מבוססת RBAC** 
- 📊 **מניעת קונפליקטים והקצאות אוטומטיות**
- 🎨 **ממשק משתמש מתקדם עם Drag & Drop**
- 📱 **תמיכה בזמן אמת עם WebSocket**
- 📈 **דוחות ואנליטיקה מתקדמת**

## 🚀 התקנה מהירה

### דרישות מקדימות
- Node.js 18+
- PostgreSQL 13+
- Redis 6+
- npm 8+

### התקנה

1. **התקנת מסד הנתונים**
```bash
# יצירת מסד חדש ב-PostgreSQL
CREATE DATABASE educational_scheduling;

# יצירת משתמש
CREATE USER scheduler_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE educational_scheduling TO scheduler_user;
```

2. **התקנת Redis**
```bash
# התקנה והפעלת Redis
redis-server
```

3. **התקנת הפרויקט**
```bash
# הקלדת הפרויקט
git clone <repository-url>
cd educational-scheduling-system

# התקנת תלות
npm install

# הגדרת משתני סביבה
cp .env.example .env
# ערוך את .env עם פרטי ההתחברות שלך
```

4. **הגדרת מסד הנתונים**
```bash
# הרצת מיגרציות
npm run db:migrate

# הוספת נתוני התחלה (אופציונלי)
npm run db:seed
```

5. **הפעלת השרת**
```bash
# הפעלה במצב פיתוח
npm run dev

# או הרצה במצב ייצור
npm run build
npm start
```

## 🧠 לוגיקת שיבוץ

### סדר עדיפויות להקבצות
1. **בדיקת כיתות אם פנויות** (עדיפות גבוהה)
2. **חדרי הקבצה ייעודיים** (עדיפות בינונית)
3. **חדרי ממ"ד** (עדיפות נמוכה)
4. **חדר 302** (עדיפות נמוכה, מועדף לאנגלית)

### חוקים מיוחדים
- **מתמטיקה**: 2 שיעורים רצופים, פעמיים בשבוע
- **אנגלית**: מפוזר יותר, עדיפות לאותו חדר
- **שיבוץ כפול**: אסור בכל מחיר
- **סיום יום שישי**: עד 12:00
- **שכבה ה'**: הימנעות יום שני ככלל

### הקצאות אוטומטיות
- **דידקטיקה ביום שני**: העברת כיתות ה' אוטומטית
- **אירועים באולם גדול**: הקצאת פעילויות אחרות
- **שימוש מרובה**: התראות לוועד ניקיון אחרי 4 שימושים

## 📊 מבנה נתונים

### ישויות מרכזיות
- **Users**: משתמשים עם הרשאות RBAC
- **Rooms**: חדרים עם מאפיינים וחוקים
- **Grades**: שכבות (א'-ו')
- **Homerooms**: כיתות אם
- **StudyGroups**: הקבצות
- **Assignments**: שיבוצים
- **ReassignmentLogs**: יומן שינויים
- **Notifications**: התראות
- **AuditLogs**: יומן ביקורת

## 🔐 אבטחה

- **JWT Tokens** לאימות
- **RBAC** מלא לפי תפקידים
- **Rate Limiting** למניעת שימוש יתר
- **SQL Injection Protection** עם parameterized queries
- **Audit Trail** מלא לכל פעולה
- **Password Hashing** עם bcrypt

## 🔄 API

### נקודות עיקריות
- `POST /api/auth/login` - התחברות
- `GET /api/rooms` - רשימת חדרים
- `POST /api/assignments` - יצירת שיבוץ
- `GET /api/assignments` - רשימת שיבוצים
- `PUT /api/assignments/:id` - עדכון שיבוץ
- `GET /api/notifications` - רשימת התראות
