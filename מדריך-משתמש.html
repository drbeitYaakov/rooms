רקע

מה המערכת עושה

זו מערכת לניהול חדרים ושיבוצים במוסד חינוכי. היא מונעת כפילויות, מציעה חדר מתאים, ומציגה בזמן אמת מה תפוס ומה פנוי.

לבקש חדר

שולחים בקשה עם סוג פעילות, שכבה, מספר תלמידים, תאריך ושעות. המערכת ממליצה על חדר.

לשבץ בפועל

שיבוץ ידני חד-פעמי או תדיר, או שיבוץ אוטומטי להקבצות שנבחרו.

לראות את התמונה

לוח שנה מאוחד, סטטוס חי של חדרים, ודוחות ניצולת וקונפליקטים.

לנהל את הבסיס

חדרים, כיתות אם, שכבות והקבצות — הוספה, עריכה, מחיקה והקצאת מורה.

איך נכנסים ויוצאים

מסך הכניסה → אחר כך כפתור «התנתק» בראש כל דף
  1. פתחו את כתובת המערכת בדפדפן. מופיע מסך Sign in.
  2. הקלידו את כתובת האימייל בשדה Email address.
  3. הקלידו את הסיסמה בשדה Password.
  4. לחצו Sign in. אם הפרטים נכונים עוברים לדשבורד.
  5. ליציאה: בראש המסך לחצו התנתק.
אם מופיע «Invalid credentials» — האימייל או הסיסמה שגויים. אין כפתור שחזור סיסמה במסך; פנו למנהל המערכת.

איך רואים אילו חדרים פנויים עכשיו

תפריט → חדרים → אזור «סטטוס חדרים חי»
  1. פתחו חדרים. בראש מופיע התאריך והשעה הנוכחיים.
  2. לחצו רענן לעדכון מיידי. המסך גם מתעדכן לבד כל 30 שניות.
  3. סננו לפי סוג חדר, אגף, קומה וסטטוס (פנוי / תפוס / בין שיעורים).
  4. המספרים למעלה: סה״כ, פנויים (ירוק), תפוסים (אדום), בין שיעורים (צהוב).
  5. החדרים מסודרים לפי קומה. בכל כרטיס: מספר חדר, תכולה, מקרן אם יש, מי משובץ עכשיו, השיבוץ הבא, ואחוז ניצולת היום.
ירוק = פנוי · אדום = תפוס עכשיו · צהוב = בין שיעורים · אפור = לא ידוע. ניצולת מעל 80% מסומנת באדום.

איך מוסיפים חדר חדש

חדרים → הוסף חדר חדש
  1. לחצו הוסף חדר חדש. נפתח חלון.
  2. הקלידו מספר חדר. הקומה והאגף מתמלאים לבד לפי המספר (ראו בהמשך).
  3. הקלידו תכולת חדר.
  4. בחרו סוג חדר מהרשימה (כיתה אם, רגיל, ממ"ד, מוזיקה, ספרייה, אודיטוריום, קראוון, חדר רכז ועוד).
  5. סמנו «האם יש מקרן בחדר?» אם יש מקרן.
  6. אם החדר הוא גם כיתת אם: סמנו «שייך חדר זה ככיתת אם», לחצו «הוסף כיתת אם», בחרו שכבה, מספר כיתה, תכולה מקסימלית ושנת לימודים. אפשר כמה שיוכים. «הסר» מוחק שיוך.
  7. לחצו הוסף חדר או ביטול. אפשר גם ללחוץ מחוץ לחלון כדי לסגור.
בחירת שכבה בשיוך כיתת אם מעדכנת אוטומטית את סוג החדר (א → כיתה א' וכן הלאה). חייבים לפחות שיוך אחד אם סימנתם כיתת אם.

פעולה · מנהל

איך עורכים או מוחקים חדר

חדרים → עמודה «פעולות» בטבלה
  1. עריכה: לחצו ערוך ליד החדר.
  2. שנו את התכולה ו/או סמנו או בטלו מקרן.
  3. לחצו שמור או ביטול. מספר החדר לא ניתן לשינוי מכאן.
  4. מחיקה: לחצו מחק. אשרו «האם אתה בטוח שברצונך למחוק חדר זה?».
מחיקה היא סופית. אם המערכת מחזירה שגיאה, ייתכן שלחדר יש שיבוצים או כיתות אם מקושרים.

פעולה

איך מוסיפים כיתת אם

תפריט → כיתות אם → הוסף כיתת אם
  1. פתחו כיתות אם. רואים כרטיסי סיכום: כמה כיתות, כמה מורים מוקצים, ניצולת מקומות.
  2. לחצו הוסף כיתת אם.
  3. בחרו שכבה. אחרי הבחירה נטענים רק חדרים פנויים לשכבה הזו.
  4. בחרו מספר כיתה (1 עד 7).
  5. בחרו חדר מהרשימה (מוצגים מספר ותכולה). בלי שכבה הרשימה נעולה.
  6. לחצו הוסף. התכולה המקסימלית נשמרת כ־35, שנת הלימודים כתשפ״ד.

פעולה

איך עורכים, מוחקים ומקצים מורה לכיתת אם

כיתות אם → עמודה «פעולות»
  1. הקצה מורה: מופיע רק אם אין מורה. לחצו, הזינו אימייל מורה בחלון, ואשרו.
  2. ערוך: נפתח אותו חלון כמו בהוספה. שנו שכבה וחדר ולחצו עדכן.
  3. מחק: אשרו «האם אתה בטוח שברצונך למחוק כיתת אם זו?».
בטבלה רואים שם כיתה, חדר וסוג, מורה (או «לא הוקצה מורה» באדום), תלמידים נוכחיים מול מקסימום, וסטטוס פעילה/לא פעילה.

פעולה

איך מייצאים דוח תפוסה של כיתות אם

כיתות אם → דוח תפוסה
  1. לחצו דוח תפוסה.
  2. הדפדפן מוריד קובץ CSV בשם שמתחיל ב־homerooms_utilization_ ותאריך.
  3. פתחו באקסל. בעמודות: שם כיתה, חדר, תכולה, תלמידים נוכחיים, ניצולת %, מורה, סטטוס. בתחתית יש סיכום כללי.

פעולה · מנהל

איך מנהלים שכבות

כיתות אם → ניהול שכבות  או  כתובת /grades
  1. לחצו ניהול שכבות.
  2. בטבלה: שם השכבה, רכז השכבה, תאריך יצירה.
  3. הוספה: הוסף שכבה חדשה → שם שכבה (אות אחת: א–ו) → בחירת רכז מהרשימה (לא חובה) → הוסף.
  4. עריכה: ערוך → שנו שם או רכז → עדכן.
  5. מחיקה: מחק ואשרו. מי שאינו מנהל רואה «אין הרשאות» או מסך חסום.

פעולה

איך מוסיפים או עורכים הקבצה

תפריט → הקבצות → הוסף קבוצה
  1. פתחו הקבצות. למעלה: כמה הקבצות, כמה מתמטיקה/אנגלית, סך התלמידות.
  2. לחצו הוסף קבוצה.
  3. מלאו שם קבוצה, סוג (מתמטיקה / אנגלית / דידקטיקה / אחר), שכבה א–ו, מספר תלמידות.
  4. סמנו אם נדרש מקרן ואם זו קבוצה גדולה.
  5. לחצו הוסף. לעריכה: ערוך באותה שורה. למחיקה: מחק ואשרו.
בטבלה מופיעים גם תאריך יצירה, אייקון מקרן, וסימון «שעות רצופות» אם הוגדר יותר משעה אחת.

פעולה

איך משבצים הקבצות אוטומטית

הקבצות → סימון שורות → שבץ קבוצות נבחרות
  1. סמנו הקבצות בתיבות משמאל לשם. תיבת הכותרת מסמנת/מבטלת את כולן.
  2. לחצו שבץ קבוצות נבחרות. הכפתור כבוהה בלי בחירה.
  3. המערכת משבצת לשבוע הקרוב (מהיום ועד עוד 7 ימים), בלי כפייה על קונפליקטים.
  4. נפתח חלון «תוצאות שיבוץ»: הצלחה ומספר ששובצו, או כישלון ומספר שלא שובצו.
  5. אם יש קונפליקטים או אזהרות — הם מופיעים ברשימה. סגרו ב־סגור.
אם השיבוץ נכשל בגלל חפיפה — פתרו ב«דריסת חוקים», או שנו שעות, ואז שבצו שוב.

פעולה

איך מייצאים לוח שנה של הקבצות

הקבצות → ייצוא לוח שנה
  1. אם סימנתם קבוצות — ייוצאו רק הן. בלי סימון — כל ההקבצות.
  2. לחצו ייצוא לוח שנה.
  3. יורד קובץ ICS (30 הימים הבאים). פתחו ביומן Google / Outlook / Apple.

פעולה

איך יוצרים שיבוץ ידני חד־פעמי

דשבורד → שיבוץ ידני  או  /assignments/manual
  1. לחצו «חזור» רק אם רוצים לצאת. אחרת מלאו «יצירת שיבוץ חדש».
  2. בחרו חדר מהרשימה (מספר + סוג).
  3. בחרו תאריך, שעת התחלה ושעת סיום.
  4. סוג שיבוץ: פגישה / הקבצה / אירוע / הרצאה / מבחן חוזר / הכנה למחנה / התעמלות.
  5. סוג תדירות: השאירו חד פעם.
  6. סוג פעילות: שיעור / פגישה / אירוע / הקבצה.
  7. לחצו צור שיבוץ. השיבוץ מופיע ברשימה משמאל.
אם החדר תפוס באותן שעות תופיע שגיאה עם הסבר. בחרו חדר או שעה אחרים, או השתמשו בדריסת חוקים.

פעולה

איך יוצרים שיבוץ חוזר כל שבוע

שיבוץ ידני → סוג תדירות: תדיר
  1. מלאו חדר, תאריך התחלה, שעות, סוג שיבוץ וסוג פעילות כמו בחד־פעמי.
  2. ב־«סוג תדירות» בחרו תדיר.
  3. סמנו ימים בשבוע: ראשון עד שישי. חובה לפחות יום אחד.
  4. בחרו תאריך סיום — עד מתי החזרה נמשכת.
  5. לחצו צור שיבוץ. השיבוץ יופיע בלוח השנה בכל הימים שסומנו.

פעולה

איך רואים שיבוצים קיימים במסך הידני

שיבוץ ידני → עמודה שמאל «שיבוצים קיימים»
  1. הרשימה מתעדכנת אחרי כל יצירה. אם ריקה: «אין שיבוצים קיימים».
  2. כל כרטיס מציג כותרת/סוג פעילות, תאריך ושעות.
  3. כפתור מחק מבקש אישור. אם המחיקה עדיין לא פעילה במערכת, אשרו מול מנהל או מחקו דרך דריסת חוקים / תמיכה.

פעולה

איך פותרים התנגשות בין שיבוצים

דשבורד → דריסת חוקים
  1. בצד ימין: «התנגשויות פעילות». אם אין — «אין התנגשויות פעילות».
  2. כל כרטיס אדום מציג חדר, תאריך ושעה, ורשימת השיבוצים שמתנגשים.
  3. שמור ראשון — נשאר השיבוץ הראשון, השני מתבטל.
  4. שמור שני — להפך.
  5. בטל שניהם — שני השיבוצים מתבטלים. אחרי הצלחה הרשימה מתרעננת.

פעולה

איך דורסים שיבוץ קיים

דריסת חוקים → «דריסת שיבוץ קיים»
  1. ברשימה לחצו על השיבוץ שרוצים לדרוס. הוא מסומן בכחול.
  2. הקלידו סיבה בשדה הסיבה. בלי סיבה ובלי בחירה — לא ניתן להמשיך.
  3. לחצו לביצוע הדריסה. בהצלחה מופיעה «הדריסה בוצעה בהצלחה!» והבחירה מתאפסת.
דריסה עוקפת את כללי המניעה הרגילים. השתמשו רק כשיש סיבה ברורה (אירוע דחוף, תקלה, החלטה ניהולית).

פעולה

איך קוראים את מסך הדוחות

תפריט → דוחות
  1. בראש בחרו תקופה: שבוע אחרון / חודש / רבעון / שנה. הנתונים מתחלפים מיד.
  2. דוח ניצולת חדרים: אחוז ממוצע, כמה חדרים פעילים מתוך הכל. «צור דוח מפורט» מוריד קובץ.
  3. דוח קונפליקטים: המספר הגדול הוא כמה קונפליקטים. «צפה בקונפליקטים» מייצא. לפירוט מעשי לכו לדריסת חוקים.
  4. סטטיסטיקות שיבוץ: סה״כ שיבוצים, הקבצות, שיעורים רגילים, פגישות, וגרף לפי סוג.
  5. מגמות יומיות: לכל יום כמה שיבוצים וכמה חדרים היו בשימוש.

פעולה

איך מייצאים דוח לקובץ

דוחות → כרטיס «יצוא דוחות»
  1. ודאו שהתקופה בראש המסך היא התקופה שאתם רוצים בקובץ.
  2. בחרו סוג: סטטיסטיקה / ניצולת / קונפליקטים.
  3. CSV — לפתיחה באקסל. JSON — לנתונים גולמיים.
  4. הקובץ יורד עם התאריך בשם, למשל report_utilization_2026-11-04.csv.

סיכום

באיזה סדר כדאי לעבוד בפעם הראשונה

  1. להיכנס למערכת ולוודא שהשם והתפקיד בראש המסך נכונים.
  2. לוודא שיש שכבות (ניהול שכבות) וחדרים (הוספת חדרים לפי מספרים אמיתיים).
  3. לשייך כיתות אם לחדרים ולהקצות מורים.
  4. להוסיף הקבצות (שם, סוג, שכבה, מספר תלמידות, מקרן אם צריך).
  5. לשבץ הקבצות אוטומטית, ואז להשלים חריגים בשיבוץ ידני.
  6. לבדוק בלוח השנה ובסטטוס החי שאין חפיפות. אם יש — דריסת חוקים.
  7. מכאן ואילך: בקשות חדר לפעילויות חד־פעמיות, ודוחות בסוף השבוע.
זהו מדריך ראשון שמקיף את כל הפעולות הקיימות במערכת כרגע. שמרו את הקובץ ופתחו אותו בדפדפן בכל הדרכה.
